Wide-column NoSQL

Apache Cassandra

Masterless, peer-to-peer, LSM-tree distributed store with tunable consistency. Built for massive write throughput and multi-DC active-active.

Time-series

InfluxDB

Purpose-built for metrics/events. v3 Core uses object storage + Apache Arrow/DataFusion; tags, fields and line protocol.

Document

MongoDB

BSON document store with flexible schema, replica sets for HA and sharding for horizontal scale. WiredTiger storage engine.

Neo4j

Native graph DB with index-free adjacency and Cypher. Ideal for connected data: fraud, knowledge graphs, recommendations.

How to use

Each architecture.html is a self-contained, offline interactive viewer — click components to read what they do and toggle the write/read path. The *.md files cover schema, pros/cons, use cases and step-by-step local deployment (Docker). Pinecone has no self-hosted option; its deployment guide shows the local SDK workflow plus a Qdrant self-hosted alternative.
